长江雨课堂 AI 学习助手 · 快速使用说明
========================================

这是一个非官方开源学习辅助工具，不会自动填写或提交作业。
完整说明见同目录的“使用说明.md”。
最新版本：https://github.com/ghenczz/rainclassroom-ai/releases/latest


一、安装
--------
1. 下载 rainclassroom-ai-v0.5.2-dist.zip
2. 解压到一个固定目录，例如 D:\Tools\rainclassroom-ai\
3. 打开 Edge，地址栏输入：edge://extensions/
4. 打开左下角“开发人员模式”
5. 点击“加载解压缩的扩展”
6. 选择解压目录里的 dist 文件夹
   （这个文件夹里应该有 manifest.json）
7. 点击浏览器右上角拼图图标，把扩展固定到工具栏


二、配置 API
------------
1. 先到 DeepSeek 开放平台创建自己的 API Key：
   https://platform.deepseek.com/api_keys
2. 点击扩展图标，打开右侧侧边栏
3. 点击“设置”
4. API 地址填：https://api.deepseek.com
5. 模型 ID 填：deepseek-chat（推荐）
6. 粘贴你自己的 API Key
7. 保持勾选“自动分析新题目”
8. 点击“保存设置”
9. 浏览器弹出权限提示时，点击“允许”

注意：API Key 只保存在你自己的电脑上。
不要把 Key 发给朋友，也不要截图发到群里。


三、使用
--------
1. 打开雨课堂作业页面
2. 点击扩展图标，打开侧边栏
3. 点击左侧“题目”
4. 检测到题目后会自动分析
5. 查看候选答案、解析和置信度
6. 切换到下一题时，侧边栏会自动更新

关闭侧边栏后不会自动调用 API。


四、结果说明
------------
- 候选答案不是标准答案，仅供参考
- 置信度低于 75% 时，扩展会提示需要人工核对
- AI 没有读取课程教材，课程特定答案请以教材和老师为准
- 判断题和单选题已验证；多选题尚未全面验证；填空题暂不支持


五、常见问题
------------
1. 找不到扩展图标
   点击浏览器右上角拼图图标，把扩展固定到工具栏。

2. 侧边栏空白或一直读取题目
   确认当前是作业页，刷新页面，然后在 edge://extensions/ 重新加载扩展。

3. 显示“尚未完成 DeepSeek 配置”
   到“设置”里填写 API 地址、模型 ID 和 API Key，然后保存。

4. 提示 401 或 403
   API Key 错误、过期或余额不足，到服务商控制台检查。

5. 提示 404
   API 地址或模型 ID 不正确，核对服务商文档。

6. 题目乱码
   等待 1-2 秒让扩展解析字体；仍然乱码就刷新页面或切换题目。

7. 提示“无法可靠读取当前题目”
   可能是填空题（暂不支持），或字体/页面结构尚未匹配。
   扩展不会猜测不可靠的题目内容。

8. 视频可以后台播放或倍速吗
   不可以。本工具不绕过平台“必须保持页面打开”的观看限制。


六、隐私
--------
- 不读取密码
- 不读取或导出 Cookie
- 不自动填写或提交作业
- 只有你主动分析，或开启自动分析且侧边栏打开时，题目才会发送到你配置的 API


七、分享
--------
把 rainclassroom-ai-v0.5.2-dist.zip 和本说明发给朋友即可。
朋友需要自己申请 API Key，不要共用你的 Key。
